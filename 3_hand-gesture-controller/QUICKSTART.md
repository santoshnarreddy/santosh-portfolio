# Quick Start — Hand Gesture Controller

## Install
```bash
pip install -r requirements.txt
```

## Optional (Windows — for audio volume control)
```bash
pip install pycaw comtypes
```

## Optional (for brightness control)
```bash
pip install screen-brightness-control
```

## Run
```bash
python gesture_controller.py
```

## Gesture Map
| Gesture | Action |
|---------|--------|
| ☝️ Index finger only | Mouse move |
| ✊ Fist | Left click |
| ✌️ Peace (index + middle) | Volume / Brightness level |
| 🖐️ Open palm (all fingers) | Screenshot |

Press `q` to quit.
